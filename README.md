# 🛒 E-commerce Full Stack


Aplicación web de comercio electrónico desarrollada con **Spring Boot y Angular**.

Proyecto Full Stack que implementa un flujo completo de compra:
usuarios, productos, carrito, checkout y gestión de pedidos.

Incluye un panel de administración para gestionar productos y pedidos.


---

# 🚀 Funcionalidades


## 👤 Cliente

- Registro e inicio de sesión
- Autenticación mediante JWT
- Visualización de productos
- Detalle de productos
- Variantes:
  - talla
  - color
  - stock
- Carrito de compra
- Checkout
- Creación de pedidos
- Consulta de pedidos


## ⚙️ Administrador

- Panel administrativo
- Gestión de productos
- Crear productos
- Editar productos
- Eliminar productos
- Gestión de marcas
- Gestión de categorías
- Gestión de pedidos
- Cambio de estado de pedidos


Estados de pedido:

- Pendiente
- Pagado
- Enviado
- Entregado
- Cancelado

# ⚙️ Instalación


## Backend

```bash
cd backend

mvn spring-boot:run
```


## Frontend

```bash
cd frontend

npm install

ng serve
```


Aplicación:

```
http://localhost:4200
```


API:

```
http://localhost:8080
```
